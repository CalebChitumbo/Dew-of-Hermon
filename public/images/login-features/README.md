# Login page feature photos

Photos shown in the two "Open Now" cards on the login landing page.

Replace these files with the photos you want to feature. Keep the
**exact filenames** — the login page references them by name.

| Filename                  | Card on the login page              | Suggested |
| ------------------------- | ----------------------------------- | --------- |
| `potters-shockers.jpg`    | Potter's Shockers · Sunday Braai    | Food or fundraiser photo |
| `rops-camp.jpg`           | ROPs X · 2026 camp registration     | Camp / youth / outdoor photo |

## Tips

- **Aspect:** the card crops to roughly a square thumbnail on the left
  of the card (object-cover, center). Photos with the subject roughly
  centered work best.
- **Size:** anything from ~600×600 up to ~1600×1600 is fine. JPG keeps
  the file small; PNG works too if you re-export with the same name.
- **Tone:** the cards sit on a dark brand panel, so warm/well-lit
  photos read more clearly than dim ones.
- After replacing a file, hard-refresh the browser to bust the cache.
